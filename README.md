# CombatSystem

Dự án Unreal Engine 5.6 với hệ thống chiến đấu sử dụng Gameplay Ability System (GAS).
**Demo:** [YouTube](https://youtu.be/ekGjJGo_4mA?si=BcoEgjusbbuINZid)  
**Repo:** https://github.com/Anhtn139/Test_AnhTN.git

## Cách chơi

**Level chơi:** `Content/ThirdPerson/Lvl_ThirdPerson.umap`

### Điều khiển

| Phím | Hành động |
|------|-----------|
| **W A S D** | Di chuyển |
| **Space** | Nhảy |
| **Left Shift** | Dodge ( né tránh ) |
| **E** | Parry ( đỡ đòn ) |
| **Q** | Khóa mục tiêu |
| **O** | Mở pause menu |
